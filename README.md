# Incantery Tap

## How do I install these formulae?

`brew install incantery/tap/<formula>`

Or `brew tap incantery/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "incantery/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
